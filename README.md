# ShopEase — Full-Stack Deployment & Project Architecture

A responsive e-commerce product catalog capstone project.

## Features
- Modular frontend structure
- Client-side routing using URL hash routes
- Node.js + Express REST API
- Product search and category filtering
- Shopping cart using localStorage
- Responsive CSS Grid/Flexbox layout
- Lazy-loaded product images
- Production-ready deployment configuration

## Run locally

```bash
npm install
npm start
```

Open:
http://localhost:3000

## Routes
- `#/` Home
- `#/products` Product catalog
- `#/about` About
- `#/product/1` Product details

## Deployment
Push this folder to GitHub and deploy the repository on a Node-compatible platform such as Render. Use:
- Build command: `npm install`
- Start command: `npm start`

The platform will provide the final public URL.
